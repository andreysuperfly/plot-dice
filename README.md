# Кости сюжета

Генератор идей для квестов. Бросаешь кости и получаешь основу квеста: что движет героем, сюжет из четырёх шагов, что делает игрок, какой выбор перед ним и какой секрет спрятан для внимательных. Дальше придумываешь сам.

**Открыть:** https://andreysuperfly.github.io/plot-dice/

## Из чего собирается квест

- **Завязка.** Цель (чего хочет герой), конфликт (что мешает), мотивация (почему не бросит) и ставка (что потеряет, если не выйдет). Расшифровка видна при наведении на подпись. Цель, конфликт и мотивация — по схеме Дебры Диксон «Goal, Motivation & Conflict», ставка — из сценарных учебников. Из этих четырёх частей складывается идея квеста. Завязки лежат готовыми связками: четыре части придуманы вместе, и большой бросок выдаёт связку целиком. Кубик на одной части меняет только её — берёт ту же часть из другой связки.
- **Сюжет: четыре шага по порядку.** Шаги работают парами: конец (4) отвечает на начало (1), проверка (3) — на помощь (2).
- **Действие.** Что игрок делает руками. Наборы под жанр: приключение, экшен, выживание.
- **Выбор.** Развилка с двумя путями и последствием, которое аукнется позже.
- **Секрет.** Пасхалка для внимательных, на прохождение не влияет.

Действие, выбор и секрет привязаны к шагу сюжета. Пунктирные стрелки показывают, откуда каждая карточка растёт.

- **История.** Под схемой все карточки собраны в короткий связный рассказ: сначала идея, потом шаги по порядку. Наведи на кусок текста — подсветится его карточка; нажми — страница перейдёт к ней.

## Типы историй

| Тип | Основа | Шаги |
|---|---|---|
| Сказка | функции Владимира Проппа («Морфология сказки»), сведённые к четырём шагам | Начало · Помощь · Проверка · Конец |
| Детектив | классическое расследование | Событие · Улика · Ложный след · Разгадка |
| Ограбление | фильмы про ограбления | Замысел · Подготовка · Срыв · Развязка |
| Тихая история | японская схема кисётэнкэцу: без борьбы и злодея, держится на повороте | Начало · Развитие · Поворот · Итог |
| Трагедия | античная схема: получил желаемое и заплатил | Желание · Шаг к цели · Расплата · Потеря |

## Как пользоваться

- **Кнопка с костями** (или пробел) — выпадет новый квест.
- Кнопки на карточке: **кубик** — другой вариант этой карточки (если **удержать** кубик или нажать правой кнопкой, откроется список всех вариантов — выбери нужный), **замок** — карточка не изменится при броске, **карандаш** — написать своё (карточка закрепится сама).
- **на шаге ▾** — перенести действие, выбор или секрет к другому шагу сюжета.
- **Назад / Вперёд** — вернуться к прошлому варианту. Клавиши: `1`–`4` — перебросить шаг, `⌘/Ctrl+Z` — назад.
- **Скопировать** — квест целиком обычным текстом. **Избранное** хранится только в этом браузере.

## Как добавить свои карточки или перевести

Весь сайт — один файл `index.html`, без сборки и зависимостей. Колоды лежат в начале скрипта отдельным блоком данных: `SKELETONS`, `BUNDLES` (завязки: цель, конфликт, мотивация, ставка), `MOTIVE`, `PACKS`, `CHOICES`, `SECRETS`. Чтобы добавить вариант, допиши строку в нужную колоду. Чтобы перевести, переведи тексты в этих блоках и подписи интерфейса.

У каждого типа истории две колоды пар: `p14` (шаги 1 и 4) и `p23` (шаги 2 и 3). Каждая пара — это `[[название, пояснение, фраза для истории], [название, пояснение, фраза для истории]]`. Фраза для истории пишется с маленькой буквы, без точки: перед ней встанет «Сначала», «Потом», «Затем» или «В конце», и второй элемент пары должен отвечать на первый.

---

**Plot Dice** is a quest idea generator for game writers: a motive, a four-step plot (Propp's fairy tale, detective, heist, kishōtenketsu, tragedy) with paired steps, a player action, a choice with a delayed consequence, and a hidden secret. Roll, lock, rewrite, or hold a die to pick from the full list. Below the board the cards are stitched into a short story; hover a sentence to see its card, click to jump to it. One static HTML file, no build step. The interface and decks are in Russian for now; all content lives in plain data blocks inside `index.html`, ready for translation.
